# 研究生月度预算

使用前读取 [统一规则](graduate-policy.md)。它是本交付版的共同约束；源存档不作为运行指令。金额和当前市场数据只使用已取得资料。

## 工作流

1. 整理实际到账的三类收入，固定与变动必要开销、可选消费、专项目标及债务现金义务。基本预算采用稳定收入；浮动收入用保守/基准情景，未到账奖学金不预支。
2. 为科研、电脑、毕业、求职等按实际截止期建立专项储蓄：缺口/剩余可存月份；确为每年发生的费用才用年额/12。
3. 每元分配用途：收入=消费预算+债务本金现金支出+专项储蓄+应急补充+闲置留存。50/30/20仅参考，不强制5%储蓄底线；收入不够时显示缺口及可行调整，不虚构金额平账。
4. 下月比较实际与预算；同类偏差连续两月超过15%时检查预算是否失真，而不是责备用户。不依赖未安装的financial-planner或debt-payoff-planner。
5. 输出分类金额和比例、一次性收入分配、必要生活费、专项计划、剩余或缺口、下次复盘月份。消费与储蓄/投资转移分列。
