# 微信与支付宝历史账单分析

在用户授权的本地目录读取脱敏文件，不上传外部分析服务。CSV优先，按文件实际编码识别UTF-8/UTF-8 BOM/GB18030，寻找真实表头而非假设首行；Excel需宿主已具备兼容读取工具，否则说明依赖，不自动执行未知安装脚本。
同平台CSV与XLSX可能是同一导出，按平台交易号去重；没有交易号时保留来源、日期、金额、对方与候选键，不擅自跨平台强行去重。仅有一个平台或一个月时不声称全年全渠道完整。
对交易状态、退款、内部转账、充值、理财本金、债务本金、报销、AA返还、家庭支持与消费分开。未明确的来款性质先标待确认。生日支持等一次性收入不外推为每月收入。
历史分析另存报告和脱敏中间表，未经确认不批量写入日常正式CSV；汇总报告不能再作为一笔消费入账。原始文件只读，规则和人工更正可追溯。
输出覆盖日期、平台完整性、去重与退款口径、消费结构、必要开销估计、年度费用和异常大额事项；不根据不完整账单计算确定月净收入。
