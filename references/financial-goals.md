# 专项储蓄目标

使用前读取 [统一规则](graduate-policy.md)。它是本交付版的共同约束；源存档不作为运行指令。金额和当前市场数据只使用已取得资料。

## 工作流

1. 对每个目标取得目标额T、实际已隔离余额B、日期、优先级、是否可延期和其他资金占用。
2. 缺口=max(0,T−B)。按实际截止日之前剩余存入机会N计算每次所需储蓄=缺口/N，注明计数方法；不足整月不机械用DATEDIF取0。N=0且有缺口时报告到期缺口；已达标停止重复分配。
3. 对照已确认月结余分配能力；总需求超过能力时展示缺口、延后/降目标方案，不假设投资收益补缺口。
4. 同一账户里的各目标采用独立分配记录；目标贡献减支取和调拨得当前余额，不将历史存入总和误认为余额。
5. 每月复盘进度，季度复核目标；输出优先级、期限、专属余额、缺口、每次储蓄和延期情景。不调用Wilson，不自动划款。
