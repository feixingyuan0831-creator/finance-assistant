# 财务助手 · finance-assistant

中文个人财务管理 Agent Skill。适用于研究生生活费、补助、学费、毕业储蓄和长期稳健投资研究，也可用于一般个人收支。适配支持 `SKILL.md` 的Agent；提供可选Obsidian本地财务库工具。

## 能做什么

- **每日记账**：自然语言输入，日期/金额/类型确认，唯一交易ID防重复；按总额管理，不必提供付款账户。
- **资金核对**：起点和已含交易避免重扣；未知不当零；完整资产、日常储蓄、独立投资账户分别统计。
- **预算与存钱**：固定/浮动/一次性收入、补助停发、学费等年费、应急覆盖期、毕业及其他专项、储蓄里程碑。
- **应收借款**：未到账与现金分开，本金归还不算新收入。
- **月度复盘**：支出结构、净结余、预算偏差、目标影响；记录不完整时明确标注。
- **历史账单分析**：本地微信/支付宝导出识别、去重、退款和转账区分；由Agent处理，不附自动导入程序。
- **投资研究**：红利低波/宽基ETF、债券基金、QDII、A股现金流及分红、季度配置复核；数据日期、费用、估值和回撤口径明确。
- **Obsidian同步**：正式CSV → 每交易一条Markdown、Bases表格和首页；变更前备份，手改冲突停止。

自然语言理解、账单分类和研究由宿主Agent完成；Python脚本负责留空建库和确定性同步。它不是独立手机App，不连接银行、券商或微信，不自动下单、不默认后台运行。已有微信宿主可另行授权接入同一账本，见[接入边界](references/obsidian-local-vault.md)。

## 安装

下载仓库ZIP并解压，把包含 `SKILL.md` 的 `finance-assistant` 文件夹放到宿主技能目录。不要把真实账本放在本仓库中。

Codex常见用户目录：`~/.codex/skills/finance-assistant`；Claude Code常见用户目录：`~/.claude/skills/finance-assistant`。也可使用宿主提供的技能安装器；路径和发现方式以当前宿主版本为准。安装后重开对话并调用 `$finance-assistant`，或在支持的技能菜单中选择“财务助手”。

仅使用指令和模板不要求Python。运行本地工具需 **Python 3.10+**，只用标准库，不需要pip依赖。Obsidian为可选应用；本包不附安装器、不自动装社区插件。

## 第一次使用

把下面指令发给Agent，替换目录为自己的绝对路径：

> 使用 $finance-assistant，在【私人财务目录】建立财务档案。金额未知请留空。先核对资产和债务，再做应急金、月度预算及专项储蓄。不要连接金融账户。

可选手工初始化与同步（在本Skill根目录）：

```powershell
python scripts/init_vault.py --vault "D:\PersonalFinance"
python scripts/sync_obsidian.py --vault "D:\PersonalFinance" --as-of YYYY-MM-DD
```

把第二条日期替换为本人时区的实际日期。初始化不覆盖已有文件；已有库初次同步前先让Agent检查。默认余额起点、目标、月度完整性均未知。只有本人确认金额与时点后，Agent才能设置现金起点，不能把初始null改成虚构0元。

## 常用说法

- “今日记账：午饭【金额】元、日用品【金额】元，只按总额记，显示今日、本月支出和余额。”
- “补助只发部分月份，请按实际发放日历做预算，不预支奖学金。”
- “把证券账户连同现金独立核算，不计入我的毕业储蓄目标；完整资产仍需展示。”
- “这笔借款已归还【金额】，更新现金和应收，不要当新收入。”
- “分析这两份账单，先辨别重复导出和退款，不要直接把历史明细重记到账本。”
- “做【月份】复盘，区分实际和计划，展示储蓄目标与未解释差额。”
- “研究我给出的基金，先说适合度；标注官方数据日、费用、估值、历史回撤和持有期，不买卖。”

## Obsidian里看什么

把私人财务目录作为vault打开：`财务首页.md`看今日/本月支出、余额及目标；`流水浏览.base`看交易表；`private/`放资产和目标；`随手记.md`暂存待录事项，由Agent确认登记；`reports/`放复盘。不要直接改交易镜像金额再当新流水导入。

不同余额范围须明确标签，学费即使放在活期也不等于可以重复计入毕业开销后目标。当前同步器对全部目标使用同一余额范围；不同范围目标由Agent另做报告。

## 隐私、许可证和限制

发布包只含通用代码、留空模板、规则和合成测试，不含任何用户资产、流水、聊天、账号、凭据、银行授权或本机路径。实际数据放在仓库外；不要提交私人vault。个人数据不会由本包脚本发往网络，但使用云端Agent时，输入内容仍由相应服务处理。

MIT；第三方改编模块分别保留原许可证，见[来源说明](SOURCES.md)。有许可证表述冲突的历史来源不在公开包中分发，相关研究说明已独立编写。
本包不提供实时行情服务、收益保证、可执行回测引擎或金融交易功能。定时提醒、微信收发、外部数据工具需宿主能力和本人另行授权。
